# Критическое исправление горизонтального скролла на мобильных устройствах

## Проблема
На мобильных устройствах (особенно в Telegram Mini App) главная страница сайта имела горизонтальный скролл. Справа было огромное пустое пространство, и весь контент можно было двигать влево-вправо.

## Решение
Применены жёсткие CSS-правила с `!important` для принудительного отключения горизонтального скролла и ограничения всех элементов шириной viewport.

## Внесённые изменения

### Файл: `src/index.css`

Добавлены следующие правила в начало файла (после `@import "tailwindcss"`):

```css
/* Принудительное отключение горизонтального скролла */
html, body {
  overflow-x: hidden !important;
  width: 100% !important;
  max-width: 100vw !important;
  margin: 0 !important;
  padding: 0 !important;
  box-sizing: border-box;
}

*, *::before, *::after {
  box-sizing: border-box !important;
  max-width: 100% !important;
}

/* Запрет на выход любых элементов за пределы viewport */
body {
  position: relative;
  min-height: 100vh;
  background-color: var(--color-ink);
  color: var(--color-fog);
  font-family: var(--font-body);
  -webkit-font-smoothing: antialiased;
}

html {
  scroll-behavior: smooth;
}
```

## Что делают эти правила

### 1. `html, body` блок:
- `overflow-x: hidden !important` — полностью отключает горизонтальный скролл
- `width: 100% !important` — устанавливает ширину ровно 100%
- `max-width: 100vw !important` — ограничивает максимальную ширину viewport
- `margin: 0 !important` — убирает все внешние отступы
- `padding: 0 !important` — убирает все внутренние отступы
- `box-sizing: border-box` — включает border-box для корректного расчёта размеров

### 2. Универсальный селектор `*`:
- `box-sizing: border-box !important` — гарантирует, что padding и border включаются в ширину элемента
- `max-width: 100% !important` — ни один элемент не может выйти за пределы родителя

### 3. `body` блок:
- `position: relative` — устанавливает контекст позиционирования
- `min-height: 100vh` — гарантирует минимальную высоту viewport
- Сохранены все существующие стили (цвета, шрифты, сглаживание)

### 4. `html` блок:
- `scroll-behavior: smooth` — плавная прокрутка по якорям

## Почему использован `!important`

Обычные CSS-правила могут переопределяться другими стилями, особенно из Tailwind CSS. Использование `!important` гарантирует, что эти правила имеют наивысший приоритет и не будут переопределены.

## Тестирование

После внесения изменений проверьте:

1. **Мобильные устройства (320px - 768px)**
   - Нет горизонтального скролла
   - Контент не выходит за пределы экрана
   - Нет пустого пространства справа

2. **Telegram Mini App**
   - Сайт корректно отображается в WebView
   - Нет горизонтальной прокрутки
   - Все элементы видны и доступны

3. **Десктоп (1920px+)**
   - Сайт работает как обычно
   - Нет визуальных изменений
   - Все функции работают

## Дополнительные рекомендации

Если проблема всё ещё возникает на некоторых устройствах, проверьте:

1. **Inline стили в компонентах** — убедитесь, что нигде не заданы фиксированные ширины в пикселях
2. **Изображения и видео** — должны иметь `max-width: 100%` и `height: auto`
3. **Абсолютно позиционированные элементы** — проверьте, что они не выходят за пределы контейнера
4. **Flexbox и Grid контейнеры** — убедитесь, что не заданы фиксированные ширины
