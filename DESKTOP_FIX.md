# Исправление десктопной вёрстки после отката !important правил

## Проблема
Предыдущее исправление горизонтального скролла на мобильных устройствах использовало глобальные CSS-правила с `!important`, которые сломали десктопную версию сайта. Страница входа растягивалась на всю ширину экрана вместо центрированного контейнера.

## Причина
Глобальные правила с `!important` переопределяли все остальные стили:
```css
*, *::before, *::after {
  max-width: 100% !important;  /* Это ломало десктопную вёрстку */
}
```

## Решение
Откатили проблемные правила и применили корректный подход:

### 1. Удалены глобальные !important правила
Убраны следующие правила из `src/index.css`:
```css
/* УДАЛЕНО */
html, body {
  overflow-x: hidden !important;
  width: 100% !important;
  max-width: 100vw !important;
  margin: 0 !important;
  padding: 0 !important;
}

*, *::before, *::after {
  box-sizing: border-box !important;
  max-width: 100% !important;  /* Это ломало десктоп */
}
```

### 2. Применены разумные базовые стили
Добавлены в `src/index.css`:
```css
/* Базовые стили */
html {
  scroll-behavior: smooth;
  overflow-x: hidden;  /* Без !important */
}

body {
  background-color: var(--color-ink);
  color: var(--color-fog);
  font-family: var(--font-body);
  -webkit-font-smoothing: antialiased;
  overflow-x: hidden;  /* Без !important */
}
```

### 3. Мобильные адаптации через медиа-запросы
Все мобильные адаптации остались через медиа-запросы:
- `@media (max-width: 768px)` - планшеты и мобильные
- `@media (max-width: 400px)` - маленькие мобильные (iPhone SE)
- `@media (max-width: 640px)` - адаптация таблиц

## Ключевые принципы

### 1. Не использовать !important глобально
`!important` должен использоваться только для точечных переопределений, а не для глобальных правил.

### 2. Использовать медиа-запросы для адаптации
Вместо глобальных ограничений ширины, использовать:
```css
@media (max-width: 768px) {
  .container {
    padding: 16px;
  }
}
```

### 3. Правильный подход к overflow
```css
/* Правильно */
body {
  overflow-x: hidden;  /* Предотвращает горизонтальный скролл */
}

/* Неправильно */
*, *::before, *::after {
  max-width: 100% !important;  /* Ломает десктоп */
}
```
